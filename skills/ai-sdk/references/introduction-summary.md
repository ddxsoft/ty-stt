# AI SDK Introduction Summary

- The AI SDK is a TypeScript toolkit for building AI powered apps and agents with React, Next.js, Vue, Svelte, Node.js, and more.
- It standardizes integrating AI models across supported providers so developers focus on product instead of provider differences.
- Two main libraries: AI SDK Core (unified API for generating text, structured objects, tool calls, and agents) and AI SDK UI (framework agnostic hooks for chat and generative UI).
- The SDK supports multiple model providers and offers templates to get started.

Source: https://ai-sdk.dev/docs/introduction
